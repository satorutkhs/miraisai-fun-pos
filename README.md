# 未来祭 FUN ROBO LAB レジ

学校祭用のオフラインPOS。Androidタブレット1台・受付1か所。レシートは出さず、事前印刷の伝票に手書き(整理番号は印字済み、個数は「正」の字)。

## 公開URL(デプロイ先)
https://satorutkhs.github.io/miraisai-fun-pos/

`main` へのマージで GitHub Pages に自動デプロイされる。タブレットは初回のみオンラインで開き「ホーム画面に追加」→ 以降はオフライン動作。更新後はオンラインで一度開き、閉じて開き直すと新しい版になる。

## 商品・料金
| 内容 | 金額 |
|---|---|
| ミルクマキアート / エスプレッソマキアート | 各300円(価格・割引とも同じ扱い) |
| ホットサンドハーフ(キャベツ抜きも同価格) | 300円 |
| ホットサンドハーフ2個 | 500円 |
| マキアート+ホットサンドハーフ | 500円 |
| マキアート+ホットサンドハーフ2個 | 700円 |
| アイスコーヒー | 200円 |

セット割引は、マキアート・ホットサンドハーフの組み合わせが常に最安になるよう自動計算(`src/pricing.ts`)。コーヒーは割引の対象外。

### ラストセール(最終日の売り切り用)
画面右上の「ラストセール OFF/ON」で切替(端末内に保存・オフラインで即時反映)。単品とコーヒーは据え置きで、セットのみ下がる。

| 内容 | 通常 | ラストセール |
|---|---|---|
| ホットサンドハーフ2個 | 500円 | 400円 |
| マキアート+ホットサンドハーフ | 500円 | 400円 |
| マキアート+ホットサンドハーフ2個 | 700円 | 600円 |

価格表は `src/pricing.ts` の `REGULAR` / `LAST_SALE`。CSVの `sale` 列が1ならラストセール価格での会計。

## 開発(Mac)
```
cd /Users/satoru/Developer
git clone git@github.com:satorutkhs/miraisai-fun-pos.git
cd miraisai-fun-pos
nvm use          # .nvmrc (Node 22)。なければ nvm install
npm install
npm run dev      # 開発サーバ(同一Wi-Fiのタブレットからも http://<MacのIP>:5173 で確認可)
npm run check    # 型チェック + テスト(コミット前に)
npm run build    # dist/ を生成(PWA)
npm run preview  # ビルド結果の確認(Service Workerはこちらで確認)
```

### ブランチの流れ
```
git switch main && git pull
git switch -c feat/○○     # fix/ chore/ も可
# テストを先に書く → 実装 → npm run check
git push -u origin feat/○○
# GitHubでPRを作成 → CIが通ったら main にマージ → 自動でPagesにデプロイ
```
`main` に直接pushしない。

## 本番(タブレット)への入れ方 — 前日までに会場外のWi-Fiで
1. `main` にpush → GitHub Actions が Pages にデプロイ(リポジトリ Settings → Pages → Source: GitHub Actions)。
2. タブレットのChromeで公開URLを開く(1回読み込めばOK)。
3. Chromeメニュー → 「ホーム画面に追加 / アプリをインストール」。
4. **機内モードにして**ホーム画面のアイコンから起動し、注文→会計ができることを確認。

## 当日の運用
- 画面右上「次の伝票 No.N」が、次に使う伝票の印字番号。会計確定後に出る番号と手元の伝票が一致しているか確認。
- 伝票の番号とズレたら「売上・履歴 → 次の番号を変更」で合わせる。
- 間違い会計は「売上・履歴 → 取消」(番号は欠番として記録に残る)。
- 「CSV保存」でこまめにバックアップ(端末のダウンロードに保存)。
- ブラウザのサイトデータは消さないこと(履歴が消える)。

## 伝票(A4縦・複写想定)
- 左半分: 整理番号(お客様用) / 右半分: 整理番号+注文個数(調理用、「正」で記入)

## データ
端末内の localStorage に保存(キー `pos.*`)。通信は一切しない。
